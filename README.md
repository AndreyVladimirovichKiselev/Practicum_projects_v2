# Practicum_projects
Portfolio of educational projects in financial analysis and modeling. The repository contains 4 cases that demonstrate skills in management reporting, budgeting, plan‑fact analysis, and scenario modeling.
## Projects

### 1. Financial Results of the Delivery Direction (“Tobi”)
**Task:** finalize management reporting (Balance Sheet, P&L, Cash Flow, Statement of Changes in Equity) for 2026; calculate missing data in orange cells.  
**Result:** 4 fully completed reporting forms; consistency check of key indicators.  
**Skills:** Excel, reporting logic, balance equation control.

### 2. Budget for New Kihi Projects
**Task:** digitize strategic goals and build a budget for 2026–2027 for two new projects; fill in the orange cells.  
**Result:** final budget aligned with goals; payback and profitability calculations.  
**Skills:** financial planning, template-based modeling, forecasting.

### 3. Plan‑Fact Analysis of New Business Directions
**Task:** perform variance analysis, draw conclusions, and prepare recommendations to improve the budget model; create a presentation for management.  
**Result:** factor decomposition of deviations; risk mitigation recommendations; stakeholder presentation (.pptx).  
**Skills:** plan‑fact analysis, factor decomposition, communicating results to stakeholders.

### 4. Financial Model: Development Scenarios
**Task:** build a downside scenario considering risks (raw material price growth, receivables, marketing inflation); compare with the base case; visualize EBITDA and EBITDA margin.  
**Result:** sensitivity model; quantitative impact assessment of risks; key effect visualization.  
**Skills:** scenario modeling, risk analysis, financial result visualization.

## Tools
- MS Excel: formulas, Power Query, pivot tables, charts.
- MS PowerPoint: stakeholder-ready materials.
- Financial analysis: plan‑fact, factor analysis, scenario modeling.

## How to Use This Repository
1. Go to the folder of the project you’re interested in (e.g., `Project_1_Financial_Results`).
2. Open the Excel file to review the calculations.
3. In `Project_3_Plan_Fact_Analysis`, you’ll also find the presentation showing communication skills with management.
